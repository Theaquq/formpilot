采集的体态照片

要求赤脚自然站立、穿贴身运动衣物、双臂自然下垂、全身入镜、镜头水平。 系统会校验四视图是否齐全，并主动拦截重复文件——重复照片会让评估结果失真。

说明：本次仅提供一张侧面照片，右侧面缺失。系统没有用同一张照片冒充两个视角， 因此右侧指标不纳入本案例，也不做左右侧面一致性比较。这是刻意的数据质量约束。

03

据评估结果生成的训练方案

这 5 个动作由评估结果推导，不是固定模板：出现高低肩倾向时追加单侧放松与肩胛控制动作； 常态动作只保留呼吸与核心打底。本次按新手、居家、无器械、约 20 分钟生成，每个动作约 4 分钟。

01

肋廓呼吸放松

呼吸与放松

放松肩颈辅助呼吸肌，建立肋廓扩张与躯干稳定感

5–8 个呼吸循环停留：吸气 3–4 秒 / 呼气 4–6 秒2 组

动作做法

  1. 仰卧屈膝或坐直，双脚有支撑，一手放上胸、一手放下肋廓。
  2. 鼻吸时让肋廓向前、两侧及后方缓慢扩张，肩膀保持下沉。
  3. 嘴或鼻缓慢呼气，感受下肋廓回落，不主动收腹到僵直。
  4. 连续完成呼吸循环，结束前来一次自然呼吸。

标准要点

  • 肩颈放松，躯干稳定，呼气时肋廓缓慢回落
  • 吸气时肋廓向四周扩张，呼吸保持连续
  • 节奏舒适，不追求过深或过快
02

死虫式核心控制

核心与躯干稳定

在对侧手脚活动中维持躯干稳定，为基础姿态控制打底

每侧 6–10 次停留：末端 2–3 秒2 组

动作做法

  1. 仰卧，双臂朝上，髋膝抬起约 90 度，腰部自然轻贴垫面。
  2. 呼气并轻收下肋，保持肩髋位置稳定。
  3. 缓慢将对侧手臂与腿向远处延伸，只到腰背不拱起的范围。
  4. 吸气回到起始位，换另一侧，缓慢交替。

标准要点

  • 起始髋膝约 90 度，移动过程中角度可控
  • 腰背与肩髋连线稳定，不随四肢摇晃
  • 对侧手脚协调配合，不屏息
03

上斜方肌拉伸

颈部放松

放松单侧上斜方肌，改善肩部紧张造成的高低差（两侧均练习，较紧张的一侧为重点）

每侧 20–30 秒停留：舒适拉伸点2 组

动作做法

  1. 坐直，双脚踩稳，被拉伸侧的手放在臀下或轻压椅面。
  2. 保持脸朝正前方，头缓慢倒向另一侧，至颈肩有轻度牵拉感。
  3. 另一只手仅轻放头顶，不硬拉；自然呼吸，肩膀下沉。
  4. 缓慢回到中立位，按需要换侧。

标准要点

  • 先比较两侧紧张感，较紧张侧可多停留约 5 秒
  • 头部只在舒适范围内侧屈，不强行拉扯
  • 被拉伸侧肩膀下沉，躯干不随头部侧倒
04

坐姿肩胛滑动

肩胛控制

练习肩胛骨上回旋与后倾控制，减少耸肩代偿

8–12 次停留：末端 2–3 秒2 组

动作做法

  1. 坐直，双臂自然垂在体侧，先让肩膀缓慢下沉。
  2. 保持躯干不动，双臂沿身体两侧缓慢向前上方抬起。
  3. 只到能维持肩颈放松的高度，感受肩胛骨随手臂转动。
  4. 沿原路缓慢放下，重复时两侧节奏一致。

标准要点

  • 双肩放松，肩线不歪斜或上提
  • 两侧手臂路径接近，速度与幅度均匀
  • 头、肋廓与躯干稳定，不用后仰代偿
05

靠墙滑臂

肩胸整合

改善抬臂时的肩胛协同、胸前活动度与躯干稳定

8–12 次停留：上举末端 2–3 秒2 组

动作做法

  1. 背靠墙站立，头、上背和骶骨轻触墙，腰部保留自然弧度。
  2. 双臂屈肘打开，手背或前臂尽量朝向墙面，不强迫贴合。
  3. 保持下肋不外翻，双臂沿墙缓慢上滑，到无痛末端轻伸肘。
  4. 缓慢滑回起始位，全程避免肩膀挤向耳朵。

标准要点

  • 上举时双肩放松，肩线尽量水平
  • 按活动度逐渐伸肘，不强顶肘
  • 双臂轨迹对称，下背与肋廓稳定
